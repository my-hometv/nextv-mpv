# NexTV MPV licensing release evidence

This file is deliberately NOT an approval. Do not change flags without
documented verification of the corresponding source and license obligations.

Create compliance/mpv-release-approval.txt only after review, with each of:
native_source_verified=yes
application_license_compatible=yes
notices_complete=yes
distribution_source_access=yes
legal_review_completed=yes

For each approval, document the reviewer, date, exact binary hashes,
corresponding-source repository/commit, notices, application license and
distribution plan in a separate reviewed record. Flags are attestations,
not automatic proof of compliance. A separate explicit APK approval is required.
